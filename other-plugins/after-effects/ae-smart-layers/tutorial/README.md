# 图文教程：安装 → 运行 → 检查 → 卸载

[返回首页](<../README.md>) · [完整限制](<../USAGE.md>) · [验证状态](<../VERIFICATION.md>)

> **图片说明**：下面的安装、使用、卸载图均为自制**流程示意，非 AE 真机截图**。花瓣对照图使用自绘合成测试夹具和实际 worker 区域数据，非用户实物、非 AE 截图。没有调用生成式图片工具，也没有附授权未确认的 SECOND / THE THIRD 真实素材。
>
> **验证边界**：101 项图像回归和宿主 mock 通过；尚无 AE25 真机排版或 ScriptUI 视觉验收。先用工程副本试验。

## 1. 安装到正确的 AE

双击 `AESmartLayers-Setup-1.0.0.exe`，按安装界面选择 AE 根目录或 `Support Files`。应能找到 `Support Files/AfterFX.exe`，脚本目标为 `Support Files/Scripts/AE 智能分层.jsx`，不是 `Plug-ins`。安装器不自动改 AE 安全偏好、不强制重启、不保存工程。

![安装流程示意，非AE真机截图](<images/install-flow.png>)

不安装也能运行：从[源码说明](<../source/README.md>)找到自包含 JSX，用下面的“运行脚本文件…”打开。维护用 C#/Python/测试不用复制到 AE。详细环境与权限见[安装说明](<../INSTALL.md>)。

## 2. 保存、选源，再从 AE 文件菜单运行

1. 自行保存工程，打开目标合成。图片/预合成先停在要分析的帧。
2. 在时间线多选 **1–20 个**源，可混选图片、预合成、原生文字。
3. 源需无父级、静态 2D、基本变换无动画/表达式，Position 未分离；正在提供轨道遮罩的源不能处理。
4. 选择 **文件 → 脚本 → 运行脚本文件…**，打开 `AE 智能分层.jsx`。
5. 自动开始，没有额外开始按钮或参数面板。若提示脚本文件操作权限不足，由用户核实后手动设置，程序不会代改。

![多选源、运行、进度及结果的流程示意，非AE真机截图](<images/usage-flow.png>)

## 3. 看进度，必要时取消

准备阶段显示已准备源数，原生文字另显示已测量字符数；图像逐源分析，单源计算时进度条可能等待；生成按已完成输出数显示。**不是虚构的总百分比**。

点击取消或关闭进度窗都会请求整批清理。同步测量、取帧和写层要等当前调用返回；不是立即杀进程。处理期间不要改源或源合成，不要 Undo/Redo 或切工程。若宿主异常导致恢复不全，检查错误提示和此前保存副本。

## 4. 成功后这样看结果

成功后原层**隐藏保留，不删除**；输出全选，锚点居中。每源内部按画面左到右、下到上编号，不同源不混排。临时开启原层，对照位置、边缘、样式后再自行保存。

| 你选中的源 | 你得到的结果 | 怎么确认 |
| --- | --- | --- |
| 静态、水平 LTR 点文字 | `[可编辑文字]` 单字层 | 展开 Source Text，确认是真单字，可直接改字 |
| 图片 | `[文字]` / `[非文字]` / `[类型待确认]` 图像蒙版层 | 查看蒙版区域；“文字”标签**不等于**可编辑字 |
| 预合成 | 当前源帧区域蒙版层 | 内部图层不会展开；切换时间看是否离开当前蒙版 |

**原生文字限制**：AE24.3+ API、面向 AE25。文本框、竖排/RTL、复杂连接塑形/ZWJ、Source Text 动画/表达式、文字动画器/路径、蒙版/效果/轨道遮罩不支持。可先预合成，但会变成图像路线，失去可编辑字输出。复杂字体、混合基线偏移仍需真机核对，不能把有限样式检查当作像素无损证明。

**图片/预合成限制**：当前帧蒙版不跟踪、不自动冻帧；互相粘连、重叠或被遮挡的花瓣不保证逐个拆开；复杂背景/低对比/模糊可能失败。总预算为 **20 源 / 120 输出 / 12000 轮廓点**；图像每源最多 40 区，原生每源最多 120 可见字符。

## 5. 可公开复试的自绘花瓣夹具

下面是**合成测试夹具**：上排 6 个分离椭圆花瓣，下排加上人工绘制的 `THE`。它们不来自用户实物；也不是“THE THIRD”真实素材。右栏由正式 JSX 内嵌的实际 worker 输出多边形与输入 alpha 相交后着色，颜色只为看清分区。

![自绘花瓣与THE合成夹具的实际worker结果，非AE截图](<images/synthetic-worker-regions.png>)

- [下载透明6花瓣输入](<images/petals-input.png>)：实际 worker 为 **6 OBJECT**。
- [下载透明6花瓣+THE输入](<images/petals-mixed-input.png>)：实际 worker 为 **9 区，6 OBJECT + 3 TEXT**。
- [查看实际结果分类与SHA256](<images/synthetic-worker-results.json>)。

在 AE 中：导入任一输入图 → 放进合成 → 选中该图层 → 用文件菜单运行 JSX → 核对输出蒙版。这里是让用户自行真机验收的步骤，不宣称教程已在 AE 完成上述操作。不要把本例通过推广为“所有花瓣都能分开”或“OCR 转文字”。

## 6. 卸载并核对保留文件

结束任务后运行 `AESmartLayers-Uninstall-1.0.0.exe`，选择安装时的 AE 位置并核对提示。只删除哈希匹配的本插件文件；手动修改过的文件保留，不清空 Scripts。卸载不会删除工程里的已有输出层或用户工程。

![卸载流程示意，非AE真机截图](<images/uninstall-flow.png>)

手动复制/免安装用户的处理方法见[卸载说明](<../UNINSTALL.md>)。修改过的脚本先备份，不要盲目删除。
