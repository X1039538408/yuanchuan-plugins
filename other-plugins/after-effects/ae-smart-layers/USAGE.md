# 使用与边界

[返回首页](<README.md>) · [图文教程](<tutorial/README.md>) · [安装](<INSTALL.md>)

## 1. 准备并运行

1. **自行保存工程或另存副本**。脚本不会保存工程；AE 渲染期间不能提交。
2. 打开目标合成，把时间指针停在要分析的帧。图片/预合成输出不跟踪动画；想保留固定帧，请先准备静帧源。
3. 选择 **1–20 个**图片、预合成或原生文字源层，可混选。
4. 在 **文件 → 脚本 → 运行脚本文件…** 中打开 `AE 智能分层.jsx`。已安装脚本位于 AE 的 `Support Files/Scripts`；不安装时也可直接选发布源码中的自包含 JSX。
5. 自动进入准备、分析和生成进度，无需再点开始。纯原生文字批次完成测量后跳过图像 worker。
6. 成功后，原层隐藏但不删除；全部输出被选中，锚点居中并补偿画面位置。每源按画面左到右、下到上编号，时间线区域 1→N 从下往上；不同源不混排，不改变其他旧层的相对顺序。
7. 临时开启源层，对照边缘、文字位置、字号与样式；检查完成后自行保存。锚点/位置相关表达式仍可能因居中产生变化。

## 2. 输入与输出不要混淆

| 输入 | 拆分方式 | 输出能否直接改字 |
| --- | --- | --- |
| 原生文字层 | 从原始富文本取真正单字/受支持字符组合，并测量定位 | **可以**，`[可编辑文字]` 层的 Source Text 是单字，不是隐藏整串 |
| 图片 | 按可见前景、间隙与形状证据分区 | **不可以**，即使标签为 `[文字]` 也只是图像蒙版 |
| 预合成 | 取当前时间对应源合成画面，考虑 startTime/stretch/当前 Time Remap 值 | **不可以**，不展开内部层、不改原合成内容 |

空格和换行保留排版间距，不生成空图层。类型判断只是规则/模板推测；`[类型待确认]` 是有意保留，不代表已经理解对象语义。本版不是 OCR，也不包含笔画恢复功能。

## 3. 所有源的共同限制

- **无父级、静态 2D**，Anchor Point / Position / Scale / Z Rotation 不得有关键帧或表达式，Position 不得分离维度。
- 正在给其他层提供轨道遮罩的源会导致整批拒绝。
- 一批最多 **20 源、120 输出、12000 轮廓点**；图片/预合成每源最多 40 区，原生文字每源最多 120 个可见字符，源文字另限 2000 UTF-16 单位。达到单源上限不代表可绕过全批上限。
- **处理时不要编辑源、源合成、时间映射、蒙版/效果属性，不要 Undo/Redo 或切工程。** 预提交复检不是完整变更检测，尤其不保证检测到同数量属性改值或预合成内部编辑。

## 4. 原生可编辑文字的支持范围

支持静态、水平、从左到右（LTR）的**点文字**，面向 AE25，需 AE24.3+ `CharacterRange`。可尝试常用中文/拉丁、多显式行及左/中/右对齐。自动字偶距不会单独导致拒绝，但仍需通过几何一致性检查。

以下不支持，会安全停止整批，**不会偷偷降级为图片**：

- 段落文本框、竖排/RTL、连接书写或复杂塑形、ZWJ 组合；
- Source Text 关键帧/表达式、文字动画器、文字路径；
- 原生文字层带蒙版、效果或轨道遮罩；
- 无效基线、上下文排版/连字几何不一致，或检测到字符内容/有限样式丢失。

可把不支持的文字先预合成，再按画面拆，但输出会变成**不可改字的图像蒙版**。常见代理对、组合音标、变体选择符、旗帜对及肤色修饰不会简单按半个 UTF-16 字符拆开；这仍不是完整 Unicode 字素引擎，不保证所有 emoji/字体塑形可无损分开。

有限样式与几何检查不等于逐像素无损。复杂字体、同边界 glyph 替换、特殊段落属性继承及混合 baselineShift 仍需 AE 真机叠原层验证。本版**没有 AE25 真机排版测试**。

## 5. 图片、预合成和花瓣

- 透明/干净背景、主体之间有清晰间隔时更适合分区。边界近似双线性模型的平滑渐变底可尝试处理；不是通用渐变、聚光或纹理抠图。
- 非文字对象不会仅因“不是字”被全部忽略；但**粘连、重叠、遮挡的花瓣不保证逐瓣拆开**，无法从单帧恢复遮住的部分。
- 极低 alpha、低对比、超小细节、模糊或复杂背景可能失败或待确认；前景碎片超过安全限也会拒绝。
- 输出沿用原图片/预合成来源，以**当前帧蒙版**隔离区域；不跟踪、不自动冻帧或烘焙。动画离开蒙版后可能被裁掉。

## 6. 进度、取消与恢复

- 准备显示已准备源数；原生文字另显示已测量字符数。分析按逐源真实阶段显示，单个源运行时进度条可能等待；生成显示已完成输出数，不伪造整体百分比。
- **取消按钮或关闭进度窗**均是取消请求。图像 worker 通过取消标记协作停止，不保证立即杀进程；同步快照、测量和写层要等当前调用返回。
- 生成期取消会尝试删除本批输出、恢复源 enabled/locked 与提交前选择；最后一次进度更新时取消也走回滚。
- 准备/分析期间重新运行会替换旧任务；测量/快照/提交/回滚的变更锁期间不能重入。不要用反复点击运行来催进度。
- 取消/错误后先核对工程。不可恢复的删除、撤销组或预览恢复异常不能保证百分之百恢复；保留错误提示，必要时人工撤销或回到此前保存副本。

## 7. 常见问题

| 现象 | 先检查 |
| --- | --- |
| 菜单找不到脚本 | 用“运行脚本文件…”直接选择 JSX，不必为了刷新菜单强制重启 |
| 文件操作权限不足 | 用户自行核实并在 AE 首选项“脚本和表达式”允许脚本文件操作；脚本不会代改 |
| 图像分析不能启动 | Windows PowerShell 5.1、Windows Script Host 是否可用；遵循组织安全策略，不关闭防护 |
| 拒绝原生文字 | 查看是否文本框/动画器/效果等不支持项；预合成可走画面路线，但不再可改字 |
| 想恢复原图层 | 原层仍在，只是成功后隐藏；检查后可重新启用。取消尚未完成时不要编辑工程 |
| 图像标为“文字”但不能编辑 | 这是分类标签；只有原生文字输入才产生可编辑 Source Text |
