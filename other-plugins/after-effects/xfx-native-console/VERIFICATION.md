# 1.0.17 安装器构建记录

发布内容：2026-10-18 本地工作区的 Windows x64 AEX 和单文件安装器。版本仍标记为测试版，不代表全部功能通过最终宿主验收。

## 本次通过

- AE SDK 必要头文件检查。
- Release x64 原生插件构建、安装器 C++/资源编译及链接。
- 实际 EXE 内四个资源与打包输入逐一核对 SHA-256：AEX、默认译名表、第三方声明和中文 ScriptUI 面板。
- PowerShell 安装事务测试：新装、升级保留用户数据、锁定文件回滚、非 AE 目录拒绝和失败清理。
- C++ 安装器测试：多目标事务、命令行解析、强制终止测试进程及回滚。
- 搜索核心、设置、控制台支持、ExtendScript 桥接、主题和菜单测试。

安装器 EXE 为 5,247,488 字节。精确 SHA-256 见 SHA256SUMS.txt。构建验证使用 PowerShell 7；旧 Windows PowerShell 对未带 BOM 的 UTF-8 脚本曾出现中文字符串解析错误。

单文件安装器包含运行所需资源；不包含 Adobe SDK、参考原安装器、个人配置、调试日志或私人素材。
