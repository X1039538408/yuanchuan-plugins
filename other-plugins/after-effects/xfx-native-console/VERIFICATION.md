# 效果控制台 1.0.18 构建与验证

日期：2026-10-19。此版改名、移除强制关闭 AE，并新增独立卸载器及可构建源码；仍为测试版。

## 本轮通过

- Release x64 AEX 构建；安装器和卸载器 C++/资源编译链接。
- 两个发行 EXE 的 ProductName 均为“效果控制台”、FileVersion 为 1.0.18.0；实际 PE 清单均要求管理员权限，未混入测试权限清单。
- 实际安装 EXE 的四项嵌入资源 SHA-256 与 AEX、词库、许可和 JSX 输入一致。
- C++ 安装/卸载测试：伪 AE 运行时拒绝操作且进程存活；提示保存退出；升级备份、旧工具栏迁移、精确文件清单、用户/其他插件保留、文件锁及跨版本事务回滚、重复卸载和 CLI。
- PowerShell 安装事务测试和六种进程名识别测试。
- 完整 wWinMain 入口生命周期测试：临时 Unicode 目录新装、升级、一键卸载、重复卸载、四项载荷哈希；安装/卸载/PowerShell 三种路径均拒绝运行中的伪 AE；目录 junction 不能把卸载重定向到外部文件。
- 生命周期测试只把清单编译为 asInvoker 以便普通会话运行，业务入口与发行源码相同。测试使用复制的 PING 伪进程，不结束真实 AE；这不能代替发行 EXE 的真实提权安装验收。
- 搜索核心、设置、ExtendScript 桥接、主题测试通过；ScriptUI 工具栏 VM 测试 26 组通过。
- 从 source/ 导出的源码单独复制到验证目录，使用本地自备 Adobe SDK，从零构建 AEX、两个 EXE，并核对四项嵌入资源通过。源码 ZIP 不包含 SDK 或任何构建输出。
- 源码白名单、个人绝对路径/凭据模式扫描及校验清单检查通过。
