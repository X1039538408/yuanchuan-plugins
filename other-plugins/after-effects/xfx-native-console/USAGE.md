# 效果控制台使用说明

## 安装与打开

请先保存所有工程并关闭所有 AE。检测到 AE 正在运行时会提示保存并自行退出，不会结束进程。双击 EffectConsoleInstaller-1.0.19.exe，在 Windows 管理员权限窗口中同意安装。完成后重新打开 AE，按 Ctrl+空格或在“窗口 → 效果控制台”打开；再次按相同快捷键关闭，失焦自动关闭。快捷键可在设置中按下新的组合键自定义。

若原 FX Console 或输入法占用同组合，请通过“设置”录制并保存其他组合，例如 Ctrl+Shift+K。新安装添加本插件、默认词库、第三方许可和中文版工具栏脚本。原 FX Console 保留，旧 XFXEnhancerBridge 脚本改名为 .disabled-* 备份。详见 INSTALL.md。

## 中文工具栏

安装器会添加 Scripts\ScriptUI Panels\效果控制台.jsx，可从 AE“窗口”菜单的脚本面板入口打开。四个按钮依次为快照、导出、设置和关于，中文提示在悬停时显示。ScriptUI 面板分支用于停靠，直接运行脚本则打开浮动 palette；真实 AE 中的完整停靠仍待验收。

工具栏与 Ctrl+空格浮窗使用同一 AEX 和设置。点击后按钮暂时禁用，等待操作实际结束；取消保存或导出不报成功。导出按钮先选择 PNG、JPG 或图片剪贴板；文件格式在确认保存位置后才渲染，使用的临时图片源在操作结束后清理。缺少配套 AEX、版本不匹配或宿主未就绪时会提示原因。

## 搜索与应用

在合成中选择一个或多个图层。控制台支持中文、拼音全拼、首字母、英文与内部标识。

| 效果 | 输入示例 |
| --- | --- |
| 高斯模糊 | 高斯模糊、gaosimohu、gsmh、Gaussian Blur |
| CC 扫光 | 扫光、saoguang、sg、ccsg、CC Light Sweep |
| 中文预设文件名 | 原中文、全拼、首字母 |

拼音忽略大小写、空格、常见分隔符，支持 ü、v、u: 与声调字母。多音字优先词组读音，可用手填拼音覆盖特殊读音。

上下箭头或鼠标移动选择，Enter 或鼠标左键应用；应用成功后控制台自动关闭。Esc 关闭，Tab 在全部/效果/预设之间切换。效果与 .ffx 均对所选图层应用，使用一次 AE 撤销组。某图层失败时保留已成功项并报告错误，可 Ctrl+Z 撤销。预设会临时隔离选择再恢复，避免重复套用。

下拉框也可筛选收藏和最近使用。每条结果右侧提供“置顶排序”“收藏”和“添加到下一个快捷槽”按钮，鼠标停留会显示功能说明；右键结果还可收藏、置顶排序、绑定九个快捷槽、用 .ffx 预设覆盖某个效果或取消覆盖。置顶顺序优先于匹配分数，并随配置保存；再次选择“取消置顶排序”即可恢复普通排序。覆盖后选择该效果将应用指定预设。搜索为空时显示已绑定快捷项，直接按 1…9 执行；结果列表中也保留 Ctrl+1…9 执行、Ctrl+Shift+1…9 绑定。顶部九宫格图标可执行和绑定；在快捷槽列表中右键对应槽位即可编辑备注或清空槽位。主界面固定显示 1–9 个快捷槽并从左到右排列，弹出菜单保持纵向顺序。

搜索框和快照、导出、快捷项、设置图标同排，所有功能控件都有悬停说明。搜索为空时，快捷槽结果固定显示 1–9 并从左到右排列；普通结果区随匹配数量伸缩，最多显示八行，其余可滚动。点击齿轮展开设置和辅助按钮。窗口需要鼠标长按可见边缘约 0.28 秒后才能拖动移动；可见的 1 像素边框也属于拖动区，确认后直接跟随鼠标移动，松开或失去鼠标捕获会停止。

快照、刷新、保存等按钮在鼠标移入时渐变高亮，移开后平滑恢复；停留约 0.6 秒显示功能说明框。设置区不再提供独立的“应用”和“收藏”按钮：应用使用结果左键或 Enter，收藏使用结果右侧星形按钮或右键菜单。

## 中文译名

结果列表统一使用“原名（中文翻译）”格式，例如 `CC Plastic（CC 塑料）`；应用效果时仍使用原始 matchName。

右键搜索结果选择“添加/编辑搜索别名”，每行输入一个别名。保存后立即生效，中文自动支持全拼与首字母；“清除搜索别名”只清除自己的别名，保留默认名称与译名。快捷槽列表右键可直接编辑对应槽位备注。别名和快捷槽备注随配置导入导出。

点击“编辑译名”打开用户词库，保存为 UTF-8。每行六列，用真实 Tab 分隔：内部 matchName、英文名称、中文译名、全拼（可空）、首字母（可空）、别名（用 | 分隔）。打开的文件内有可复制示例，去掉示例行开头的 # 才生效。

保存后点击“刷新索引”。中文译名和别名自动生成拼音，也可手填。译名优先级为用户词库 → 旧版兼容词库 → 默认词库 → 内嵌词库。品牌及内部标识保持原文。当前词典 660 行，覆盖内置效果及部分第三方效果；行数不代表已覆盖全部外部插件，未知效果保留原名，不改变第三方参数面板。1.0.19 补充部分 Sapphire/BCC+ 擦除译名，并兼容 `BCC+` 后有无空格。

## 保存当前合成快照

激活合成后点击相机按钮“保存当前合成快照”，直接打开 PNG 保存对话框。默认文件名为当前合成名，可修改名称并选择本地保存位置。点击确认后，插件才将当前时间帧按完整分辨率渲染为 PNG；取消对话框不会生成文件。设置中不再提供分辨率开关。

1.0.17 已移除快照图库、固定截图位置和清缓存入口。旧版已保存图片保持原样，可继续用系统资源管理器访问。

## 导出当前合成帧

点击“导出”，选择透明 PNG、白底 JPG（质量 95）或图片剪贴板。PNG/JPG 可选择文件名与保存位置，确认后才渲染导出，取消不会生成文件。剪贴板导出直接复制当前帧图片，接收软件可能以自己的方式处理 alpha。

导出使用临时图片源并在操作结束后清理，不写入旧版图库目录。高位深/色彩管理项目需在真实 AE 中核对导出颜色；跨应用粘贴仍需实机验收。

## 设置与数据

“设置”展开快捷键、配置导入导出、输入法模式和界面主题。快捷键标签、输入框和保存按钮垂直对齐，设置区域保持紧凑。默认快捷键是 `Ctrl+Space`，点击快捷键输入框后按下新的组合键即可保存；再次按相同快捷键会关闭浮窗，浮窗失焦也会自动关闭。固定窗口与自动关闭开关已移除。

主题下拉框提供“跟随 / 浅色 / 深色”，随配置保存；保存失败保持旧主题。“跟随”在呼出时读取宿主背景，无法读取则回退为 AE 深灰。菜单、编辑窗口及工具栏自绘使用同一调色板。当前构建的测试结果与宿主验收限制见 VERIFICATION.md。系统文件对话框及宿主拥有的区域沿用系统/AE外观。

可选输入法功能只改变当前 IMM 输入法的中/英文模式，关闭时恢复，默认关闭。部分第三方输入法不支持此接口。

快捷槽备注和别名会随配置一起保存。

系统文档目录 LoYoi\XFXNative 下保存 settings.ini、aliases.user.tsv 和 install.log。旧版 Capture 目录及其中图片保留；新快照保存到对话框选择的位置。配置采用 UTF-8，保存收藏、最近、槽位备注和预设覆盖。卸载保留个人数据。

当前构建为测试版。早期构建在本机 AE 2025（25.4x86）完成插件注册、目录搜索、两层效果/预设、透明 PNG 和项目导入验收；该实机记录不覆盖后续新增界面。实际键盘呼出、输入法组合、全部第三方效果及原版逐像素对照仍需人工验收；当前构建与验收边界见 VERIFICATION.md。
