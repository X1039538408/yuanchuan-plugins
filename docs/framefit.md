# 视频套版 FrameFit

**发来视频，说出要求，在自己的电脑得到成片。**

FrameFit 把“批量工具”的视频套版流程接入 Codex。适合短视频批量转换横竖版、统一品牌模板、调整视频窗口和快速导出；通过自然语言执行，也可打开配置面板逐项设置。

## 实际使用

首次在 Codex 添加 `X1039538408/yuanchuan-plugins` 市场、安装 **视频套版 FrameFit**，在新聊天中通过 `@` 选择插件：

> 把这些视频套用内置横版模板，1080P，高画质，保留原声，直接导出。

Codex 读取当前电脑可访问的视频，准备配置并开始导出，返回任务进度、完成结果和逐条错误。要求明确时直接执行；需要自定义模板或缺少必要参数时再补充。

> 打开面板，预览第 3 秒；改成完整显示，导出到 D:\成片。

面板支持素材队列、模板、自动／手动窗口、四种适配方式、缩放、分辨率、画质、编码和本机预设。视频位于模板上方，放大能覆盖装饰，符合原工具的合成规则。

## 在另一台电脑使用最新版

使用电脑需为 Windows 64 位，安装支持插件与本地 MCP 的 Codex。首次需要安装插件并联网下载便携运行包，无需独立安装原软件、Python、Node 或 FFmpeg，也无需 GitHub 登录。之后用 `@` 调用已安装插件。

维护者通过 PR 修改源码，并发布稳定版本；其他电脑准备新任务时检查更新，获取新的处理功能、面板、共享模板与预设。正在导出的任务保持原版本。网络不可用且有已验证缓存时可以继续旧版，并显示实际版本。

插件技能、名称、MCP 接口和启动器更新仍需刷新市场，必要时重启 Codex 或新建聊天。自动同步针对已发布的稳定版本，不会把尚未发布的本机修改自动发送给其他人。

## 本地处理与使用条件

视频在每台使用电脑处理，设备需保持开机。个人配置、素材和任务日志不上传；共享模板和预设作为公开 Release 内容发布。浏览器无法直接推断附件的本机路径，宿主未提供可访问路径时需填写实际路径。

支持批量失败隔离、取消保留成片和继续未完成项目。自动编码优先 NVIDIA，必要时回退 CPU；强制 NVIDIA 需要兼容显卡和驱动。插件不收使用费，Codex 自身账号和额度遵循用户已有服务。
