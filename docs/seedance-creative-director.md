# Seedance 创意导演：功能与创意约束说明

Seedance 创意导演是一套用于共创中文视频提示词的插件工作流。它适合从参考图片、几句剧情、已有脚本或一版待修改的提示词出发，把想法发展成动作清楚、镜头可理解、前后状态连贯的画面描述。

你不需要先填写一整张需求表。可以先说「让这个像素少年在山门前拔剑，气氛紧张，细节你补」，再通过对话逐步确定方向。插件会区分哪些是你已经确认的要求、哪些是它提出的创意、哪些关键问题还需要回答。

本文介绍仓库中 0.1.25 版本的工作规则与设计目标，不代表视频模型每次都能精确执行。插件原始入口见 [SKILL.md](../plugins/seedance-creative-director/skills/seedance-director/SKILL.md)，完整模块见 [模块索引](../plugins/seedance-creative-director/skills/seedance-director/references/modules.md)。

0.1.25 修复了右侧视频生成控制面板下拉选项为空的问题：面板优先使用 PowerShell 7，正确读取 UTF-8 控制器输出并展开嵌套账号数据；账号选择会触发级联刷新，画布模型的模式、比例、分辨率和时长从实时能力动态生成。未读取到能力时仍显示明确错误，不会伪造可选值。

## 一、创意如何展开

创意模块负责为已有意图设计具体表达。简略脚本中的普通执行细节和表达留白，可以主动补全；影响故事方向的重要选择，需要结合已有设定和授权范围判断。

| 创意方向 | 可以帮助设计的内容 | 补全时注意什么 |
| --- | --- | --- |
| 动作与表演 | 动作准备、路径、接触、反应、停顿，以及紧张、犹豫、释然等可见表现 | 先让主动作清楚，再安排衣摆、环境等次要运动 |
| 镜头与构图 | 景别、观察方向、镜头路径、前景、留白、构图和结束画面 | 围绕叙事目的选择，不把环绕、一镜到底或第一视角设为通用模板 |
| 光影与氛围 | 已有光源的方向与落点、冷暖、明暗、色彩及环境变化 | 沿用既定时间、天气和画风，不为了氛围凭空改变场景事件 |
| 节奏与衔接 | 主次、停顿、多动作顺序和镜头之间的连接 | 保留关键动作的完成证据，不把过多事件压进同一瞬间 |
| 故事与因果 | 目标、阻碍、选择、行动与结果的衔接 | 理论服务于任务，不强制反转、悲剧、三幕结构或固定节拍 |

例如「少年拔剑，紧张」可以展开为停步、肩膀微收、调整握姿、拔出剑、剑尖指向既定方向后短暂停住。如果画面和脚本没有敌人，不会仅凭“紧张”就确定山门里藏着仇人，再扩写一场复仇战斗。

## 二、哪些内容直接补，哪些先沟通

这里的创意约束主要保护用户意图和故事内部一致性。它允许积极创作，也允许法术、梦境、变形、瞬移和像素表现；判断重点是这些变化是否符合已经建立的世界规则。

| 遇到的情况 | 工作方式 |
| --- | --- |
| 拿杯子但没写如何伸手、走到门前没写停步 | 直接补必要动作，无需逐项询问 |
| 只说“夕阳下重逢”，没指定景别和表演 | 主动提出适合的镜头与表现 |
| 道具此前丢失，下一幕却用它开门 | 先明确是否取回、是否改写前一事件，或是否使用另一种开门方式 |
| 人物前面救人，后面无缘由杀死同一人 | 先沟通动机、误认或其他设定，避免自行确定关键原因 |
| 同时要求“完全固定镜头”和“环绕人物” | 指出具体冲突，询问取舍 |
| 用户明确说“动机和结局你来定” | 在授权范围内选取一致方向，简短说明关键设定并继续创作 |

提问通常围绕最影响后续的一个关键问题，给出可理解的方向。尚未回答的问题不会自动变成同意；不受该问题影响的素材整理或镜头内容仍可继续。已经回答的决定在当前对话内沿用，不反复索取确认。

## 三、六类约束如何保护创作

### 1. 意图与修改继承

最新明确修改替代与它冲突的旧要求，其他已经确认的内容继续有效。插件提出的补全只是创作选择，不能在后续对话中悄悄变成用户硬要求。

例如你说「只把结尾改成他收剑离开，其他不动」，修改应集中在结尾及必要的连接处，保留人物、场景、开头、台词和其他已确认动作。定稿时整合完整最新版，减少让你自行拼接多轮片段的负担。

如果你明确把“一镜到底”改成“三个镜头切换”，直接按新要求更新；如果要求“保留一镜到底，再加三个硬切”，则先沟通两者如何取舍。

### 2. 素材用途与外观

人物图、场景图、动作视频、运镜参考和声音素材各有用途。同一素材可以承担多个明确用途，但不会自动把其中所有内容带入成片。

例如人物图 A 配动作视频 B，要求「让 A 照 B 拔剑，背景还是 A 的山门」，就提取 B 的动作路径和节奏，保留 A 的人物与背景。B 中的现代街道、服装和音乐不会自动成为新设定。

人物、商品和道具未被要求改变的属性应持续继承。指定换装、损坏或变形时，改变相应属性，其余保持稳定。首帧负责起始状态，尾帧负责到达状态，中间要交代如何连接；不能用未经确认的梦境或新能力掩盖身份突变和因果缺口。

原图需要保留的 Logo 与“禁止新增 Logo”分别处理。看不清的文字、背面标识或未能读取的素材，不会冒充已经观察到的事实。

### 3. 动作状态与可见结果

关键动作按「起始状态 → 路径或接触 → 可见变化 → 结束状态」组织，关注角色位置、手部占用、道具位置和数量、门或容器开合，以及跨镜头的结果继承。

“收剑”需要剑进入剑鞘的可见过程；“交出杯子”需要接收者接稳、原持有者松手；“装盒并离开”需要物体入盒、手离开、按剧情关盖、拿起盒子再离开。只说“成功完成”不能代替这些证据。用户只要求放入盒子时，也不额外强加离开的剧情。

如果左手提灯、右手持剑，却要双手推开重门，可以在允许范围内安排放灯或收剑。若同时要求两件道具全程不松手，则先询问取舍。已设定的法术移动或时间跳跃按故事规则处理。

当动作超出指定时长时，先减少自行加入的装饰细节；仍然无法自然完成，再讨论延长、拆分或允许的省略范围。

### 4. 镜头与空间

固定镜头中，人物、衣物、树叶、水面等仍可运动；但用户要求“完全固定镜头”时，应保持机位、朝向、焦距和构图，不额外加入推进、变焦或环绕。

一镜到底要求镜头连续。允许的近景或特写应通过连续运动实现，不暗中改成硬切、跳切或隐藏剪辑。未要求固定构图时，首帧只是起点，不自动限制后续运镜。

人物相对位置、行动轴线、视线和道具关系应当可理解。摄影机换位不会自动意味着人物换位置；复合运动需要明确先后、方向和终点，避免同一时段出现互相冲突的指令。

第一视角、第三人称跟拍与无人机 FPV 分别表达。HUD、法阵、虚拟面板等只在任务需要时加入，并说明位置与交互方式。

### 5. 台词、声音与音乐

用户指定的台词逐字保留，除非明确要求润色或授权改写。可以补充语气、停顿和动作阶段，但不会自行增加改变剧情的新台词。

角色对白、旁白、内心独白和同场画外声分别安排。旁白不会强制可见人物做说话口型；声音参考只作用于指定的音色、语速或情绪，不改变画面人物身份。

默认不主动添加后期背景音乐，可保留合理的动作音与环境音；用户指定音乐、只要音乐或全静音时，按明确要求覆盖默认值。全静音不再保留脚步声。场内弹琴、锣鼓或收音机与后期配乐分开判断，影响剧情而含义不清时再询问。

台词明显超出时长时，讨论延长、拆分或改写，不擅自删词或靠异常高速语速塞入。

### 6. 宫格分镜与格间连续性

宫格默认关闭。镜头多、动作链长或连续性复杂时，可以推荐四宫格或九宫格，并说明原因；“看看方案”只表示讨论，明确确认后才进入生成流程。

每格承担一个主要视觉事件，下一格继承上一格的人物位置、朝向、视线、手部占用、道具状态、光线和场景结构。宫格图主要表达镜头顺序、景别、构图变化和节奏，不覆盖其他素材已经明确承担的人物、场景或道具用途。

确认比例和分辨率后，当前入口优先通过已授权 LibTV MCP 使用 `Lib Image 2.5 Pro` 普通图片模型生成，不使用平台宫格快捷预设。LibTV 明确失败且用户确认回退时，才使用宿主内置生图工具。实际能力以当前会话工具为准。

宫格图生成后先展示并等待验收，再读取确认后的每格内容组织视频提示词。局部修改优先编辑已有图，保留其他格子。整张宫格图不能保证视频模型逐格、逐像素锁定构图；精确姿势和首尾状态可能需要单格裁切图或关键帧。

## 四、画风与默认偏好

像素角色通过朝向、步态、持物姿势和停顿表达情绪，不依赖难以看见的皮肤纹理。二维插画保留线条和平涂；写实画面再按需要描述材质。电影风格可用于借鉴色彩、光源、构图和空间比例，不自动复制演员、服装或影片剧情。

默认使用中文自然叙述，不统一添加 8K、电影颗粒、浅景深、写实毛孔或无关故障负向词。时长根据任务与平台选择，不固定为 15 秒；单图动画优先沿用图片画幅，但是否锁定全程构图由用户要求决定。这些默认偏好可以被明确要求覆盖。

## 五、交付、修改与生成

通常从同一份定稿派生 LibTV 版和即梦网页版，两版只改变素材引用方式，正文、动作、台词和约束一致。用户明确只要一版时输出单版。LibTV 的图片、视频和音频统一按提供顺序使用 `{{Mixed 1}}`、`{{Mixed 2}}` 等引用。

说“继续”或“恢复”时，先检查已交付到哪一步，补充缺失内容；已显示的段落视为已交付，避免网络中断后整段重放。收到新的修改要求时，重新整合受到影响的最新版。

提示词完成后，可以选择 LibTV、即梦画布或即梦对话生成视频。宿主支持时，右侧面板集中展示平台、账号、项目或会话、模型、模式、比例、分辨率和时长；可选参数由控制器读取当前能力。最终确认前只读取与预检，确认后提交；中断后使用原任务身份恢复，避免重新提交。

提示词共创依赖宿主模型；本地面板需要 Node.js，视频控制器需要 PowerShell 7 和相应 CLI／账号配置。LibTV 或即梦可能消耗平台积分。插件不会把“写好提示词”当成“视频生成成功”，也不保证下游模型精确执行所有动作和构图。

## 六、可以这样开始

> 根据这张人物图，写一段像素仙侠视频提示词：少年在山门前拔剑，紧张但克制。动作和环境细节你补，全程固定镜头，不要背景音乐。

> 检查这段剧情的道具连续性。他前面把玉佩扔进河里，结尾却用它打开石门。先给我几个修正方向，选定后再整合完整提示词。

> 只修改最后三秒：人物收剑，转身离开。保留其他已确认内容、人物外观和素材引用，给我完整最新版。

> 这段动作比较复杂，先判断是否适合九宫格，说明每格的主要事件。我确认前不要生图。

## 七、规则在哪里维护

- [创意模块](../plugins/seedance-creative-director/skills/seedance-director/references/creative)：动作、镜头、氛围、节奏、故事和宫格设计。
- [约束模块](../plugins/seedance-creative-director/skills/seedance-director/references/constraints)：意图、素材、动作状态、镜头空间、声音及宫格连续性。
- [共创与澄清](../plugins/seedance-creative-director/skills/seedance-director/references/dialogue.md)：关键问题的判断、提问和对话继承。
- [默认偏好](../plugins/seedance-creative-director/skills/seedance-director/references/preferences.md)：可由用户覆盖的默认值。
- [交付检查](../plugins/seedance-creative-director/skills/seedance-director/references/quality.md)：成品整合前的检查项。

这些文件描述插件应遵循的工作方式。实际遵循情况仍需在目标宿主和具体任务中验证，文件存在或结构检查通过不等于所有创意行为已经通过实测。
