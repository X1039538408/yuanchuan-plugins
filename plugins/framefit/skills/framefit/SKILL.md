# 视频套版 FrameFit

使用插件的 FrameFit MCP 工具执行任务。视频在当前 Windows 电脑处理，用户不需要启动原软件或登录媒体服务。

## 对话工作流

1. 从用户附件获取真实、可访问的本机路径，或使用其提供的视频／文件夹路径。不要猜测路径，也不要把远程附件 URL 当本机路径；附件无法落盘访问时，说明情况并请用户提供本机完整路径。
2. 调用 `prepare_config`，传入 `videos` 和已明确的 `config`。此步骤检查稳定版本并解析素材、模板及尺寸，返回 `sessionId` 和实际版本；后续调用使用该会话。已有会话修改配置时用 `update_config`，增删素材用带 `sessionId` 的 `prepare_config`。
3. 用户要求面板时调用 `render_panel`；要求预览时调用 `preview_frame`。数据工具不附带面板，不要为了导出强制打开面板或要求额外确认。
4. 用户要求明确且素材、模板有效时，直接 `export_videos`。每次用户导出意图创建一个唯一 `requestId`；超时或重试同一意图复用这个 ID，避免重复导出。修改参数用于下一次任务，正在运行的任务使用冻结配置和版本。
5. 用 `get_task` 查询进度，报告实际输出和逐条失败原因；保留 `taskId` 供后续查询。工具调用结束不代表导出完成；只有任务完成且对应条目有输出才交付成片。使用绝对路径链接。用户要求打开结果时调用 `open_output`。

`cancel_task` 停止任务并保留已完成结果。`resume_task` 继续失败、取消或中断任务的未完成项目。需要保存个人预设时用 `manage_presets`，共享预设只能通过仓库稳定版本发布；不把个人路径、素材和日志推送到仓库。

## 参数与判断

`config` 支持：

| 字段 | 值 |
| --- | --- |
| `direction` | `landscape` 竖转横、`portrait` 横转竖、`custom` 自定义 |
| `templateId` / `template` | 内置 `landscape`、`portrait`，或模板图片本机路径 |
| `detection` | `auto`、`transparent`、`black`、`white` |
| `rect` | 自动为 `null`，手动为模板原始像素 `[x,y,width,height]` |
| `fit` / `zoom` | `cover` 填满、`contain` 完整显示、`stretch` 拉伸、`zoom` 自由缩放；缩放 10～500% |
| `resolution` | `720p`、`1080p`、`4k`、`original` |
| `quality` / `backend` | `high`、`standard`；`auto`、`nvenc`、`cpu` |
| `outputDir` | 本机输出文件夹，默认由服务提供 |

未指定项沿用服务返回的个人配置／共享默认配置；自然语言明确要求覆盖对应项。切换方向时同步选择对应内置模板并清除旧手动窗口；使用自选模板时清除内置模板选择。自定义模式缺少有效模板、自动识别失败或参数矛盾时，只询问影响执行的缺项。

视频位于模板上方，放大后能覆盖模板装饰，仅由成片边界裁切。不要改成把模板覆盖在视频上，也不要把识别窗口当最终裁切框。保留原音频，无声输入保持无声；同名输出自动编号。

`auto` 优先 NVIDIA，编码不可用时回退 CPU；`nvenc` 是强制 GPU，失败需明确报告，不能悄悄回退。预览用于检查布局，不代表编码或整批任务已经成功。

## 更新与故障

版本以工具实际返回值为准。每次新建／准备任务检查公开稳定清单；离线且已有验证缓存时可继续旧版，向用户说明实际版本及更新警告。没有可用缓存时说明下载失败并重试，不声称已使用最新版。插件技能、名称或工具接口变更需要刷新市场，必要时重启 Codex／新建聊天。

不要为修复插件自动修改用户系统执行策略、安装全局 Python／Node 或关闭安全软件。首先报告工具给出的具体错误，并采用已提供的本机配置和重试入口。
