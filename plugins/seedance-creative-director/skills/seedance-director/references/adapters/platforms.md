# 平台引用与参数适配

这是引用和交付方式的适配层，不改变剧情。原资料的语法属于用户提供的工作流约定，未独立验证当前平台行为。

## 固定引用规则

默认输出两版；只有用户明确要求单版时才省略另一版。LibTV 版必须使用用户指定的原样占位符格式，不能改成中性素材说明、文件名或即梦标签。

将本轮用户提供的图片、视频和音频按提供顺序统一编号，并在 LibTV 正文中按以下字面格式引用：

- 第 1 个素材：`{{Mixed 1}}`
- 第 2 个素材：`{{Mixed 2}}`
- 第 3 个素材：`{{Mixed 3}}`
- 后续素材按相同规则递增，例如第 4 个素材为 `{{Mixed 4}}`。

占位符必须保留双层花括号、英文 `Mixed`、一个空格和阿拉伯数字。不要输出 `{{mixed 1}}`、`{Mixed 1}`、`@图片1`、素材文件名或其他变体。未使用的素材可以省略，但不能因为省略而重新编号；使用第 3 个素材时仍必须写 `{{Mixed 3}}`。

已知素材提供顺序即可按上述规则编写，不需要平台截图或重复确认格式，也不声称已经在平台内完成上传、绑定或执行。若素材顺序本身无法辨认，先问清顺序，不猜编号。局部修改沿用该提示词已确认的素材映射，不按新一轮文字提及顺序重新编号。

即梦网页版默认按本次真实素材文件名引用：`@主文件名`，删除扩展名及中英文括号和括号内内容。用户明确指定即梦界面编号如 @图片1、@视频1、@音频1 时，按实际存在的编号输出；不能把文件名方案与自动编号方案混用。

没有素材时，两版仍按双版本格式输出，正文不虚构素材引用。即梦版缺少真实名称或标签、无法唯一引用时，询问必要的素材映射，确认后再交付完整双版；不因即梦映射缺失而改写已明确的 LibTV 引用语法。

## 用户手册中的平台配置

| 配置 | 规则 | 启用前提 |
| --- | --- | --- |
| LibTV mixed | 按本次全部图片、视频、音频提供顺序统一编号，固定引用为 `{{Mixed 1}}`、`{{Mixed 2}}`、`{{Mixed 3}}` 等；未使用素材省略正文但不压缩原始序号 | 始终启用 |
| 即梦文件名 | @主文件名，去扩展名及中英文括号附加内容 | 默认启用，真实文件名已提供 |
| 即梦界面标签 | 使用实际 @图片1 等界面标签或用户给定标签 | 界面或用户明确提供标签 |

清理文件名后重名时，不编造平台里不存在的新名字；请求用户提供唯一真实标签或改名后的映射。给出的改名建议不是已执行的文件操作。

双平台版本从同一份定稿按素材标记替换，台词、标点、动作顺序与约束相同。两版是默认交付格式；用户明确只要单版时才省略另一版。LibTV 版的 `{{Mixed N}}` 字面格式不得被替换。

## 能力限制

平台模式、可用时长、比例、分辨率以用户当前界面或已核实官方文档为准。不得把原仓库的 30–180 秒等历史描述视为所有 Seedance 版本通用。

8K、IMAX、胶片型号、120fps 慢镜描述不等于真实输出设置。可描述希望的观感，但不承诺文件规格。未知设置不阻止撰写提示词，也不改变上述已确认的素材引用格式；不编造 API 或生成接口。
