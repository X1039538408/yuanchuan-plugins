# LibTV 图片模型适配

## 职责

本模块只负责调用 LibTV 的普通图片生成模型来生成宫格分镜图。不得调用 LibTV 图片工具栏里的“多机位九宫格”“剧情推演四宫格”或其他预设快捷项；宫格布局、逐格事件和连续性必须由 Seedance 模块写入提示词。

## 默认模型

- 首选模型：`Lib Image 2.5 Pro`。
- 生成前通过 `libtv model search --type image` 动态确认模型名称和可用参数。
- 如果首选模型不存在、未登录或当前项目不可用，先报告具体原因，不要静默换成其他模型。

## 认证来源

- 优先检查已连接的 `@LibTV` MCP 插件状态。`doctor` 和 `account_user` 成功，表示 LibTV 插件已经授权。
- `@LibTV` MCP 插件的 OAuth 状态与本地 `libtv.exe` CLI 凭据是两套独立认证。CLI 返回 `401 未登录` 不能否定 MCP 插件已经登录。
- 只有当前会话没有 LibTV MCP 工具时，才检查本地 CLI；不能用 CLI 401 覆盖已成功的 MCP 授权。

## 生成前必须询问

用户确认宫格模式后，在执行 LibTV 生成前主动询问两项：

1. 画幅比例：横屏、竖屏、方形或自定义比例；默认继承参考图比例，但必须让用户确认。
2. 输出分辨率：从当前 `Lib Image 2.5 Pro` 实际支持的选项中选择；不能凭记忆承诺 2K、4K 或具体像素。

用户未回答前，只完成提示词和选项说明，不创建生成节点、不发起生成。

## 调用流程

1. 确认宫格类型、画幅比例和分辨率。
2. 通过 `@LibTV` MCP 插件检查授权和账户，再检查当前项目。
3. 通过 LibTV 当前图片模型能力检查 `Lib Image 2.5 Pro` 的 schema，确认比例、分辨率、数量和图生图模式字段。
4. 将参考图片上传或复用为 LibTV `image` 资源节点，保留用户提供顺序和用途。
5. 创建普通 `image` 生成节点，设置模型为 `Lib Image 2.5 Pro`，写入完整宫格提示词和用户确认的比例、分辨率。
6. 按模型 schema 连接参考图；需要参考图时使用图生图模式，不把图片拼接预设当作生成器。
7. 执行节点并等待任务终态。
8. 只有节点返回成功并有有效图片结果时，才展示“已生成”；随后暂停等待用户验收。

## 失败与回退

- 未登录：说明需要登录 LibTV，保留可复制提示词并暂停。
- 如果 MCP 插件已授权但 CLI 未登录：继续使用 MCP 插件，不把 CLI 的 401 当成失败。
- 无当前项目：说明需要选择或创建 LibTV 项目并暂停。
- 首选模型不可用：说明模型不可用，询问用户是否选择其他 LibTV 图片模型；不自动替换。
- 用户已确认选项但生成失败：报告 LibTV 的错误原因，询问是否改用 ChatGPT 内置生图。
- 用户确认回退后，才加载系统 `imagegen` 技能并调用内置工具。

## 禁止事项

- 不调用 `libtv image shortcut` 生成宫格。
- 不调用外部 API。
- 不在用户未选择比例和分辨率时猜测参数。
- 不把宫格图生成成功直接视为视频提示词验收通过。
