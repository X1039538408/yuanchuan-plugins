# 宫格图像生成适配

本适配只服务于已确认的宫格模式。默认提供商是已连接的 `@LibTV` MCP 插件中的普通图片生成模型，首选 `Lib Image 2.5 Pro`。不调用 LibTV 图片工具栏的宫格快捷预设。LibTV 失败后，只有用户确认才回退到宿主提供的 ChatGPT 内置图像生成工具。

## 调用顺序

1. 先完成剧情拆镜、画幅判断、宫格数量确认和素材用途整理。
2. 把这些内容整理成一份连续分镜图生成提示词，并给每个输入图注明参考用途。
3. 读取 [LibTV 图片模型适配](libtv-image-generation.md)，主动询问并确认画幅比例和分辨率。
4. 使用 LibTV 的普通图片生成模型生成一张四宫格或九宫格连续分镜图。新图使用图生图或文生图模式；若用户要求修改已有宫格图，编辑已有图片节点并保留未修改格。不得改用九宫格、多机位或剧情推演快捷预设。
5. 只有 LibTV 明确失败且用户确认回退时，才加载系统 `imagegen` 技能并调用内置工具。
6. 只有工具返回成功结果时，才向用户说“已生成”。
7. 将生成结果展示给用户并暂停，等待“确认”“修改第 N 格”或其他明确反馈。
8. 用户确认后，才进入视频提示词生成阶段。

## 提示词契约

未来增加其他图像模型时，仍复用同一份宫格分镜提示词契约：画幅、版式、阅读顺序、逐格事件、连续性、素材用途和排除项不能因提供商切换而丢失。提供商差异只能放在适配层，不得改写剧情。

## 工具不可用

只有在 LibTV 已完成登录、项目和模型检查后仍明确返回不可用或调用失败时，才执行以下处理。不要把 LibTV 预设列表、ChatGPT 内置工具状态或其他会话状态混为一谈。

- 区分具体状态：尚未尝试、当前宿主未开放工具、调用失败。若是调用失败，保留工具返回的简短错误原因或请求标识（不泄露密钥）。
- 明确告知 LibTV 的具体失败原因，并询问是否改用 ChatGPT 内置生图；用户确认后才切换。
- 输出可复制的宫格生图提示词；
- 暂停后续依赖宫格图的视频提示词生成；
- 不静默切换到外部模型、外部 API 或未经用户确认的其他提供商。

## 修改已有宫格图

用户指定修改某一格时，优先使用已有宫格图作为编辑目标，只改变用户指定的格子及其必要衔接。未指定的格子保持人物、场景、光线、构图和风格一致。
