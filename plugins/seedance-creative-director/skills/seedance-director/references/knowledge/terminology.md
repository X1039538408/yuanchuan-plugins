# 镜头术语：中文执行表达

这是经整理的工作词典，不是必须全部加入提示词的词表。按需选择并写清对象、方向和结果。电影案例不作为技法必然有效的证明。

## 景别与取景

| 术语 | 中文表达重点 |
| --- | --- |
| EWS / Extreme Wide Shot | 大远景，说明人物在环境中的大小与位置 |
| WS / Wide Shot | 全景，主体全身及环境关系可见 |
| MWS / Medium Wide Shot | 中全景，常取膝部以上，按实际需见动作裁定 |
| MS / Medium Shot | 中景，常取腰部以上 |
| MCU / Medium Close-Up | 中近景，常取胸部以上 |
| CU / Close-Up | 面部或关键对象的特写；中文景别称谓可有体系差异，直接说明画框范围 |
| ECU / Extreme Close-Up | 眼、唇、指尖等局部极近取景 |
| BCU / Big Close-Up | 较紧的面部特写；与 ECU 用法有交叉，不硬规定比 ECU 更近 |
| OTS / Over-the-Shoulder | 从哪位人物肩后观察谁，建立位置关系 |
| Two Shot | 两人同框，说明彼此位置与距离 |
| Insert Shot | 单独呈现已有物件或信息的细节镜头，不凭空新增线索 |

## 摄影机、光学与视角

| 术语 | 正确区分及中文表达 |
| --- | --- |
| Dolly In / Out | 摄影机物理靠近/远离，说明起止景别与路径 |
| Zoom In / Out | 机位不变，变更焦距来改变取景；不同于移动摄影机 |
| Pan / Tilt | 位置不变，水平摇摄/上下俯仰；朝向改变 |
| Tracking | 跟随或平行移动，说明跟随对象和相对距离 |
| Crane / Jib | 升降或摇臂弧线运动，具体说明路径，不等同于纯垂直升降 |
| Orbit / Arc | 围绕主体移动一段弧线；方向和范围明确，不默认 360° |
| Roll | 围绕光轴旋转的运动 |
| Dutch Angle | 地平线倾斜的构图，可静止保持，与 Roll 区分 |
| Dolly Zoom / Zolly / Contra-zoom | 同一技法的常见名称：机位移动配合反向变焦，主体画面大小基本保持，背景透视关系变化 |
| Rack Focus / Focus Pull | 焦点从 A 转至 B，不自动改变景别；可配合固定或移动机位 |
| Steadicam | 稳定流畅的移动观感，仍需明确路径；不要求模型模拟实际设备 |
| Handheld | 有控制的手持晃动与跟随；强度按情境选择 |
| Aerial / FPV | 航拍不必俯冲；FPV 可描述飞行路径，不等同于人物双眼 POV |
| POV | 从指定角色眼睛位置观察，不与能看到其完整身体的第三人称镜头混写 |
| High / Low Angle | 俯拍/仰拍，说明观察对象；不自动决定善恶或权力意义 |
| Shallow DOF / Deep Focus | 有选择的景深虚化 / 多层景物清晰；说明哪些对象清晰 |
| Wide / Telephoto | 在构图与拍摄距离共同作用下呈现纵深或压缩感；不把透视仅归因于焦距 |
| Anamorphic | 可描述椭圆散景、横向眩光等观感；不自动强制输出画幅 |
| Macro / Tilt-shift | 微距细节 / 焦平面或透视控制；移轴不必总是微缩效果 |

## 光线、色彩与构图

| 术语 | 中文表达重点 |
| --- | --- |
| Hard / Soft Light | 阴影边缘清晰/柔和，说明光源方向 |
| High / Low Key | 整体明暗关系与光比，不等同于曝光错误 |
| Rembrandt | 暗侧脸颊的小三角受光；普通侧光不一定是伦勃朗光 |
| Natural / Available / Practical / Ambient | 自然光、现场可用光、画内灯具、环境照明分别表达；蜡烛是人造实景光源 |
| Backlight / Rim / Silhouette | 逆光可形成轮廓光或剪影，是否保留正面细节需说明 |
| Volumetric / God Rays | 空气介质中可见光束；与镜头内部眩光不同 |
| Lens Flare / Bokeh | 镜头眩光 / 失焦散景，不把两者统称“椭圆光晕” |
| Golden / Blue Hour | 日出日落附近暖光 / 日出前日落后偏蓝暮光，时间长度因地点季节变化 |
| Complementary / Analogous | 互补色 / 邻近色；黄绿通常不是互补色配对 |
| Bleach Bypass | 留银形成低饱和、高反差观感；与交叉冲洗 Cross-processing 区分 |
| Negative Space / Symmetry / Frame within Frame | 留白 / 对称 / 利用已有门窗等框景；没有一种适用于全部镜头 |
| Deep Space / Deep Focus | 前中后景叙事布局 / 清晰范围，二者相关但不同 |
| Film Grain | 可选胶片质感，不是消除所有数字/像素风的默认措施 |

## 时间与剪辑

- Long Take：持续较长的单个镜头；One-shot：任务范围内一个连续镜头，不必规定最低秒数。
- Match Cut：动作、形状、色彩或意义的匹配剪辑，仍可跨时间和地点。
- Hidden Cut：将剪辑点隐藏，营造连续观感；不是 Match Cut 的同义词。
- Jump Cut：刻意省略同场动作时间，不能误判成所有剧情时间跳跃的总称。
- Montage：镜头组合组织信息与压缩时间；Parallel Editing 不一定表示绝对同时发生。
- Pillow Shot / Cutaway：情绪性过渡空镜与切出镜头有交叉但不完全相同，不把所有固定镜头叫枕镜。
- Speed Ramping：描述哪一段加速/减速及过渡，不承诺生成文件具备真实高速摄影帧率。
- Time-lapse / Hyperlapse：时间压缩；Hyperlapse 还包含显著机位移动。
- Frame Stutter / Strobing：描述所需间歇运动或闪烁观感，不简单用降低帧率冒充可验证技术实现。
- Academy Ratio 通常约 1.37:1，4:3 约 1.33:1。画幅、镜头光学与平台分辨率分开指定。
