# 电影风格参考索引

用于用户提出“电影感”、具体影片或摄影方向时，将参考拆成可见元素。以下是审美方向的概括，不是逐镜考据或生成效果保证。

| 参考方向 | 可借鉴维度 | 不应自动带入 |
| --- | --- | --- |
| 沙丘式宏大极简 | 环境尺度、主体占比、克制色彩、建筑几何 | 沙虫、沙漠、科幻飞船 |
| 银翼杀手式都市疏离 | 冷暖局部对照、反射、烟雾中的光层次 | 霓虹招牌、雨夜、未来服装，除非情境允许 |
| 教父式权力关系 | 人物高低和距离、局部面部暗区、克制运动 | 黑帮身份、枪械、威士忌 |
| 花样年华式含蓄 | 遮挡、框景、停顿、局部暖色、人与空间距离 | 旗袍、香港场景、现成配乐 |
| 布达佩斯式图案感 | 对称、平面化、色彩组织、节奏 | 强制粉色、复古酒店、特定人物 |
| 小津式观察 | 低机位、稳定画框、人物调度、日常间隙 | 所有镜头必须静止、所有空镜必须无意义 |
| 战争纪实 | 有控制的手持、动作可读性、低饱和等选择 | 爆炸、血迹、胶片噪点和晃动的无条件堆叠 |
| 东方武侠 | 山水空间、留白、动作节奏、人物与环境联系 | 每个场景都竹林、所有武侠都固定镜头 |
| 动画与像素 | 轮廓、色块、层次、姿态和节奏 | 真实毛孔、光学镜头参数、消除像素的负向词 |

按具体目标选择少量相容技法，再转写成中文动作与画面语言。仅写“某导演风格”不足以控制镜头；也不把影片里未被指定的人物、物体和事件混入。

摄影师、年份、奖项和具体拍摄设备如成为用户的问题，需要另查可靠来源。原始电影目录用于线索检索，未完整复制为权威数据库。
