# 视频生成右侧控制面板

当宿主提供 `seedance-video-panel` MCP App 时，双版本提示词完成后优先打开右侧控制面板。控制器一次批量准备账号、项目/会话、素材、模型、参数 schema、积分和最近成功配置；模型不再把固定选择拆成多轮聊天问题。

## 面板职责

- 一次展示平台、即梦适配器、账号、项目/会话、素材、模型、模式、比例、分辨率、时长和积分。
- 默认复用当前线程最近一次成功配置；无历史配置时使用当前能力返回的推荐值。所有自动填充项必须可见并可修改。
- 最近 6 个项目或会话直接展示；用户需要其他项时使用搜索或刷新，不把最近 6 个误认为全部可用项。
- 切换平台、账号、适配器或容器时只刷新受影响数据；切换模型时只刷新该模型 schema。
- 预检通过后显示完整摘要，只有用户点击“确认并生成”才调用付费提交。

## 控制器工具

`prepare_video_config` 和 `refresh_video_config` 只做批量读取；`validate_video_config` 只做预检；`submit_video_config` 必须收到 `confirmed=true` 且同一 run 未提交；`resume_video_config` 只查询原 `operationRef` 或 `submit_id`。

面板没有可用时，回退到现有文字流程；不得假装已经打开面板，也不能跳过最终确认。
